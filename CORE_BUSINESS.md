# Core Business Requirements

## Product Overview
Focusdle is a habit and study management platform designed to maximize user retention, learning outcomes, and engagement through gamified features, AI-driven personalization, and defensible value propositions.

## Core Modules & Features

### Free Tier
- Quick Mode (max 3 sessions/day)
- Daily limited LLM tokens
- Local device storage for study data
- Secure, non-deletable streak tracking
- Basic reminders, quizzes, and analytics
- Limited history and leaderboard
- Ads and upgrade nudges
- Single-device usage
- Community (read-only)

### Premium Tier
- Full cloud sync (notes, chats, sessions)
- Multi-device access
- Extended LLM token limits
- Custom session limits
- Unlimited Quick Mode & Deep Mode
- Unlimited revision scheduling
- Full history & advanced analytics
- Export notes (PDF/Markdown)
- Priority AI responses
- Custom AI persona
- Smart recommendations
- Private groups, advanced leaderboard
- No ads, backup & recovery, offline sync
- Early access to new features

### Moat Features (Defensibility)
- Focus Score (behavior-based)
- Adaptive Revision Engine (AI-driven)
- Streak Insurance (freeze streak)
- Personalized AI Study Coach memory
- Habit → Deep Conversion Path tracking
- Gamified milestone rewards
- Study Identity Profile (public badge)
- Weekly performance report email
- Peer accountability groups
- AI detects shallow learning patterns and intervenes

## Business Goals
- Drive user upgrades through clear feature differentiation and defensible value
- Maximize retention with habit tracking, gamification, and adaptive learning
- Build community and social proof via leaderboards and public profiles
- Ensure data security and privacy for all users
